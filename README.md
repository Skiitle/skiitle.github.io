# Convexity Trainer

An interactive web-based training tool for learning convex optimization. 
Randomly generates optimization problems with varying objectives and constraints. 
Students practice identifying whether each problem is convex or non-convex, 
with instant feedback and explanations.

**Features:**
- Random problem generation
- Multiple problem types (QP, SOCP, non-convex examples)
- Instant correctness feedback
- Score tracking
